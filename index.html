How to use these notes

  1. Start with Cloud Computing and AWS Fundamentals.
  2. Read a topic overview, then open its subtopics.
  3. Run commands only after replacing placeholders and checking your account and Region.
  4. Complete the hands-on task and verify the result.
  5. Use the revision checklist and Print / Save PDF button for offline revision.

Security and cost reminder

  • Never commit access keys, private keys, passwords, or secrets to this website or GitHub.
  • Keep S3 public access blocked unless you have a specific, understood use case.
  • Restrict SSH access and prefer temporary credentials or Session Manager where suitable.
  • Review current AWS pricing and Free Tier terms before creating resources.
  • Delete lab resources and check for billable leftovers when finished.
